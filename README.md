## Project Overview
A fully responsive 5-page website for "The Daily Loaf", an artisan bakery specializing in sourdough bread and French pastries.

## Website Pages
| Page | File | Description |
|------|------|-------------|
| Home | index.html | Hero section, features, daily specials |
| About | about.html | Company story, team, values |
| Menu | menu.html | Categorized menu with prices |
| Order | order.html | Online ordering form with validation |
| Contact | contact.html | Two locations, contact form, FAQ |

## Features Implemented
✅ Responsive navigation bar  
✅ Contact form with JavaScript validation  
✅ Order form with item selection  
✅ Two locations on contact page (meets requirement)  
✅ Mobile-friendly design (media queries)  
✅ Semantic HTML5 structure  
✅ CSS Grid and Flexbox layouts
